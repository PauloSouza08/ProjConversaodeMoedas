O projeto de conversão de moedas feito em Java, é um exercício da matéria de TPA 9Técnicas de Programação e Algoritmos) no curso de Desenvolvimento de Sistemas em conjunto com Ensino Médio ministrado pela ETEC, Escola Técnica do Centro Paula Souza.

O programa funciona pedindo a entrada de qual meoda para qual meoda e valor para o usuário, e retorna a conversão com uma conta simples sem atualização dos valores por meio externo.

O exercício foi feito para compreensão da variavéis, uso da plataforma NetBeans com Java e reforçar a lógica de programação dos alunos.
